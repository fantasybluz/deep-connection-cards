# 深刻地認識一個人 · Getting to Know Someone Deeply

一場促進深度交流與理解的互動卡牌體驗。透過循序漸進的提問卡牌，引導參與者探索彼此內心世界，建立真實而有意義的連結。

單一靜態 HTML，沒有任何依賴後端，放到任何靜態空間就能玩。

## 玩法

- 建議人數 2–8 人，開場先由主持人朗讀開場白（中英對照）
- 四疊牌：暖身破冰卡 20、⭐ 一星連結卡 30、⭐⭐ 二星連結卡 30、⭐⭐⭐ 三星連結卡 20，共 100 張
- 點牌堆抽卡，玩家照順序輪流；抽到的卡可以「略過」放回牌堆，晚點再出現，抽牌的人不變
- 已抽過的牌記在瀏覽器（localStorage），重新整理不會重複；牌桌底下可以整場重洗

## 開發

全部內容都在 `index.html` 一個檔案裡（卡牌資料在 `<script>` 的 `DECKS` 陣列）。改完直接開瀏覽器就能看。

## 授權

卡牌內容與英文翻譯為原創。自由取用，玩得開心。
